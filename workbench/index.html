系统定位与人机协同流程

Transit Atlas 是一个辅助城市交通规划师的人机协同（Human-in-the-Loop）研究工作台。它不替代规划师决策，而是通过 7 步闭环支撑敏捷的情景研究：

  • 01 提出问题: 在研究对话框输入交通公平性或特定群体出行关切。
  • 02 Agent 提案: 检索文献与指标目录，提出研究思路、所需数据与计算口径。
  • 03 规划师审数: 核验数据来源与局限，确认本轮处理方法。若缺关键数据则停止计算。
  • 04 本地 GIS 处理: 下载并清洗公开数据，标准化到 1,597 个 400 米网格。
  • 05 Agent 建议权重: 依据问题侧重点和文献证据，提出有依据的指标权重。
  • 06 规划师调权: 审核或修改建议权重，最终确认启动运算。
  • 07 重算与空间对比: 本地 GIS 重算需求与供给等级，输出 148 基线对比地图与逐格 CSV。

空间图谱操作

左侧地图渲染新加坡 EPSG:3414 坐标系下的矢量路网与 400 米网格：

• 图层开关: 可在底部自由切换「规划区」「巴士线路走向」「巴士站点」「研究网格」图层。

• 交互点选: 鼠标点击地图上任意方格，左下角会高亮显示该网格所属规划区、Grid ID 以及入选状态（基线候选 / 保留 / 新增 / 退出）。

• 情景对照视图: 进入「情景结果」后，地图切换为保留（青色）、新增（品红）与退出（黄色）对比模式。

本地工作台特性

• 真实模型与本地算力: 当前本地工作台直接调用您本机的 OpenAI Codex CLI，模型使用您的登录凭证与配额，数据与计算全程留存在本机，保障数据私密性与可追溯性。

• 数据处理工作流: 在「数据处理」页面，您可以直接粘贴 data.gov.sg 数据集链接，本地程序会自动抓取、检查几何并按 400 米网格标准化，供研究对话选用。
